# How to Run

Clone Repository

```bash
git clone https://github.com/ziyaur-12/Design-and-Analysis-of-Algorithms-RTU.git
```

Open Repository

```bash
cd Design-and-Analysis-of-Algorithms-RTU
```

Compile

```bash
g++ filename.cpp -o program
```

Run

Linux / macOS

```bash
./program
```

Windows

```bash
program.exe
```
